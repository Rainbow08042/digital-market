Windows 可直接双击项目根目录的 `启动网站.bat`。首次运行会自动安装依赖，随后启动开发服务器并打开浏览器。保持启动窗口开启，按 `Ctrl+C` 停止网站；实际访问地址以窗口输出为准。运行前需安装符合 Vite 要求的 Node.js（20.19+ 或 22.12+，推荐当前 LTS 版本）。

```sh
npm install
npm run dev
```

生产构建：

```sh
npm run build
npm run preview
```

静态部署时，将未知路径回退到 `index.html`，以支持 `/employee/employee-01` 等详情页直接访问。
