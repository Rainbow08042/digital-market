# 数字超市

一个面向 AI 员工与业务协作场景的展示项目，帮助用户了解不同岗位的能力、适用场景与交付内容。

- 41 位 AI 员工，支持分类浏览、搜索与详情查看。
- CEO 工作台，展示业务信息汇总与跨部门协作场景。
- 岗位专属封面、工作流程与交付配图。
- 适配桌面与移动端，包含首屏视频和图片加载反馈。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

浏览器打开终端显示的本地地址。Windows 用户也可以双击 `启动网站.bat` 启动。

## 版本说明

本仓库维护可在本地运行的项目版本，与线上版本保持相同的页面、功能和展示资源。

技术栈：React、Vite、React Router、GSAP、Three.js。
